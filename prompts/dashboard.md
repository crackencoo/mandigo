# Mandigo Dashboard Prompt v0.1

## Purpose

This prompt was used to generate the first Mandigo dashboard prototype in Lovable.

## Prompt

You are a senior product designer and senior full-stack engineer.

Build the first version of a modern web application called "Mandigo".

Mandigo is not a todo app.

It is a personal operating system that helps users manage their daily life through different modules.

The application must look like a premium SaaS product similar to Linear, Notion, Arc Browser and Apple.

General design language:

- Minimal
- Modern
- Rounded cards
- Clean spacing
- Responsive
- Dark mode
- Light mode
- Purple and blue accent colors
- Smooth animations
- Professional typography

Application structure:

A left sidebar containing:

- Dashboard
- Tasks
- Calendar
- Fitness
- Nutrition
- Work
- School
- Settings

The Dashboard should contain interactive widgets.

Widgets:

- Today's Tasks
- Today's Calendar
- Weekly Progress
- Statistics
- Quick Actions

Each widget must be clickable.

Do not implement the modules yet.

When a widget is clicked, navigate to an empty placeholder page.

The dashboard should look polished and realistic.

Generate a complete React application using modern best practices.

Use reusable components.

Do not build authentication yet.

Focus entirely on the UI and navigation.

## Result

Lovable generated Mandigo v0.1 dashboard prototype.

## Review

Approved direction:

- Sidebar design is strong.
- Dark mode looks premium.
- Purple/blue accent direction works well.
- Dashboard card system is good.
- Overall SaaS feeling is aligned with the product vision.

Needs improvement:

- Dashboard should feel more personal.
- Tasks should become interactive daily modules.
- Workout and meal prep tasks need detail pages.
- Statistics should become Mandigo-specific.
- Quick Capture should be added.
