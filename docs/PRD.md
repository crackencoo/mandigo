# Mandigo PRD v0.1

## Product Name

Mandigo

## Tagline

Personal Performance Operating System

## Product Vision

Mandigo is a modular personal operating system that helps users manage their daily life, performance, training, nutrition, work, and school from one central dashboard.

Mandigo is not a simple todo app. Each task can become an interactive module with detailed instructions, media, progress tracking, and completion feedback.

## Target Users

### Admin

The admin manages personal goals, tasks, templates, calendar events, workouts, nutrition plans, work schedules, school tasks, and user progress.

### Member

The member follows daily tasks, training plans, meal prep instructions, school/work tasks, and progress assigned by the admin.

## Dashboard Purpose

The dashboard is the user's daily control center.

When the user opens Mandigo, they should immediately understand:

- What needs to be completed today
- What events are scheduled today
- Which tasks are most important
- Current progress
- Fitness and nutrition status
- Quick actions

## Dashboard Widgets v1

- Today's Tasks
- Today's Calendar
- Weekly Progress
- Statistics
- Quick Actions

## Interactive Task Concept

A task is not only a checkbox.

Example:

### Workout Task

When the user clicks a workout task, they should see:

- Workout name
- Estimated duration
- Exercise list
- Sets
- Reps
- Rest time
- Written instructions
- Video explanation
- Completion button

### Meal Prep Task

When the user clicks a meal prep task, they should see:

- Calories
- Protein
- Carbs
- Fats
- Meal list
- Recipe
- Preparation steps
- Optional video
- Completion button

### Work Task

When the user clicks a work task, they should see:

- Shift time
- Location
- Notes
- Checklist
- Completion button

### School Task

When the user clicks a school task, they should see:

- Class name
- Assignment
- Resources
- Due date
- Completion button

## Product Principles

1. Dashboard first
2. Every task can become a module
3. Minimal but powerful
4. One-click access to daily priorities
5. No dead screens
6. Completion should give feedback
7. The system should scale from personal use to PT client management

## MVP Goal

The MVP should allow a user to:

- View a premium dashboard
- Navigate between core modules
- See daily tasks
- Click a task and open a detail screen
- Track completion status
- Use dark and light mode
- Access quick actions

## Future Direction

Mandigo can evolve into:

- PT client management platform
- Workout tracking platform
- Nutrition coaching system
- School/work productivity dashboard
- Personal analytics system
- SaaS product for coaches and clients
